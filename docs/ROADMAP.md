# Roadmap

## Near term

- Add richer region adapters beyond WorldGuard
- Add hologram abstraction
- Add ProtocolLib-backed packet utilities
- Add Citizens NPC abstraction
- Add Folia scheduler implementation
- Add pagination and templating support for GUIs

## Medium term

- Introduce event bridge APIs where stable abstractions make sense
- Add service capability metadata for advanced plugin authors
- Expand placeholder resolver context support

## Long term

- Keep Anchor 1.x public APIs stable
- Evolve adapter internals without forcing downstream plugin rewrites
- Broaden ecosystem support while preserving graceful fallback behavior
